Inside the codebase

Offline application architecture

Android MainActivity.java
  → WebViewAssetLoader (bundled HTML / CSS / JavaScript)
  → movement.js · mind.js · household.js · environment.js
  → local simulation state / activity scheduler
  → Android encrypted save bridge (Keystore AES-GCM)
  → optional GGUF/JNI inference bridge [EXPERIMENTAL]

No app INTERNET permission; no hosted API required for gameplay.

Full source is organized as a dedicated Android project with JavaScript simulation and Python reference tests. The separate full-source repository is being prepared for publication.
